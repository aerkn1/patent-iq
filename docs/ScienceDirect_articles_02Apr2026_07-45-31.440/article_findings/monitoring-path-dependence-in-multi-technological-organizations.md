# Monitoring Path Dependence in Multi-technological Organizations

## Why It Matters For PatentIQ
- Strongly relevant for portfolio intelligence and strategic-change analytics.
- It shows how patent text and portfolio evolution can be used to detect organizational lock-in and path dependence.

## Key Findings Relevant To PatentIQ
- Uses patent titles and abstracts to assign patents to technological paths and then measures path dependence over time.
- Emphasizes organization-level trajectory monitoring, not only document-level classification.
- Connects portfolio structure with strategic flexibility and lock-in risk.
- Explicitly notes that titles and abstracts are a practical but limited proxy, and that fuller text or claims would improve technological substance capture.

## PatentIQ Implications
- PatentIQ can expand portfolio analytics beyond size and blocking into trajectory structure:
  - path dependence
  - concentration by technological path
  - diversification versus lock-in
  - dependence drift through time
- The new Gold history marts make this substantially more feasible than before.
- This is a good conceptual bridge between semantic clusters and portfolio strategy.

## Good Ideas To Reuse
- Build portfolio path metrics from family history plus semantic or field assignment:
  - dominant path share
  - path concentration
  - path switching rate
  - emerging-path adoption
- Surface "lock-in risk" as a strategic signal rather than a raw metric only.

## Cautions
- Text-only path assignment can overstate clarity in noisy or cross-domain inventions.
- These metrics should complement, not replace, legal and market context.
